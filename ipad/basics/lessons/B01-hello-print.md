# B01 · Hello、`print`、註解（iPad · Blank）

**裝置：** iPad · Swift Playgrounds  
**Playground 類型：** Blank／純程式輸出  
**時間：** ~15 分鐘  
**目標：** 用手指喺文件瀏覽器開第一個 playground；識 `print`；識註解。

---

## 步驟（iPad）

1. 打開 **Swift Playgrounds** → 停喺 **My Playgrounds** 文件瀏覽器。
2. 右上角 **＋** → 揀 **Blank**（或可跑 Swift、有結果輸出嘅模板）。
3. 橫放 iPad；輕觸編輯區，清走預設範例。
4. 貼下面「完整 code」（可三指捏合貼上，或外接鍵盤 ⌘V）。
5. 撳工具列 **▶**。若結果被螢幕鍵盤擋住，撳鍵盤右下角收起，或向下掃結果面板。
6. 做「練習」三條；改完再 ▶。

---

## 完整 code（可貼）

```swift
import Foundation

// 單行註解：解釋下一行做咩
print("你好，Swift Playgrounds")

/* 多行註解
   可以寫長啲說明
*/
print("Hello, Wing Kit")

// print 可以一次印多個值（用空格隔開）
print("課程", "基礎", "B01")

// 用 \n 換行（喺字串入面）
print("第一行\n第二行")
```

對應 snippet：`snippets/B01-hello-print.swift`

---

## 練習

1. 再加一行 `print`，印出你今日想學嘅一句話。
2. 用多行註解寫「呢個 playground 係 B01（iPad）」。
3. 試吓印數字：`print(1 + 2)`，睇結果係咪 `3`。

---

## 常見錯誤

| 問題 | 解法 |
|------|------|
| 字串唔出 | 要用雙引號 `"…"` |
| 改咗但結果舊 | 再撳一次 **▶** |
| 搵唔到 ▶ | 確認已打開 playground，唔係停喺文件列表 |
| 睇唔到輸出 | 收起鍵盤；橫放；輕觸「結果」相關分頁 |
