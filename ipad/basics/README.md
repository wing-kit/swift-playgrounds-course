# Swift Playgrounds（iPad）基礎教材

專為 **Wing Kit Leung** 而設：由零喺 **iPad Swift Playgrounds** 學 Swift 語言核心。全部課以 **Blank／純程式輸出** 為主（`print` 睇結果），唔使先開 SwiftUI。

語氣：粵語書面語。同 Mac 基礎軌道 **平行獨立**——只抄 code 可以，步驟請跟呢份（觸控、文件瀏覽器、▶ 位置）。

完成後去 [`../lessons/`](../lessons/) 進階（建議由 02 SwiftUI App Playground 起）。

---

## 點樣開（iPad）

1. iPad App Store 裝 **Swift Playgrounds**。
2. 開 app → 文件瀏覽器 → 右上 **＋** → 開 **Blank**（或可 `print` 嘅程式模板）。
3. 輕觸編輯區，清走預設範例；貼 `lessons/B0X-….md` 嘅「完整 code」。
4. 撳工具列 **▶**；向下／向結果面板睇輸出（橫放較易同時睇 code＋結果）。
5. 螢幕鍵盤擋住結果時：收起鍵盤，或外接鍵盤。
6. `snippets/` 可用 **檔案** app 打開複製（教材若經 GitHub／AirDrop 落喺 iPad）。

> 教材唔會遠端改你部 iPad。
