# B01 · Hello, `print`, comments (iPad · Blank)

**Device:** iPad · Swift Playgrounds  
**Playground type:** Blank / plain program output  
**Time:** ~15 minutes  
**Goal:** Open your first playground from the file browser with your finger; use `print`; write comments.

---

## Steps (iPad)

1. Open **Swift Playgrounds** → stay on the **My Playgrounds** file browser.
2. Top-right **＋** → pick **Blank** (or a template that runs Swift with a results area).
3. Hold the iPad in landscape; tap the editor and clear any sample.
4. Paste the “Full code” below (three-finger pinch paste, or hardware ⌘V).
5. Press toolbar **▶**. If the keyboard covers results, dismiss it (bottom-right) or swipe the results pane down.
6. Do the three exercises; press ▶ again after each change.

---

## Full code (paste-ready)

```swift
import Foundation

// 單行註解：解釋下一行做咩
print("你好，Swift Playgrounds")

/* 多行註解
   可以寫長啲說明
*/
print("Hello, Wing Kit")

// print 可以一次印多個值（用空格隔開）
print("課程", "基礎", "B01")

// 用 \n 換行（喺字串入面）
print("第一行\n第二行")
```

Matching snippet: `snippets/B01-hello-print.swift`

## Exercises

1. Add another `print` with a sentence about what you want to learn today.
2. Write a multi-line comment saying “This playground is B01 (iPad)”.
3. Try `print(1 + 2)` and check the result is `3`.

---

## Common mistakes

| Problem | Fix |
|------|------|
| String does not show | Use double quotes `"…"` |
| Code changed but result is stale | Press **▶** again |
| Cannot find ▶ | Open a playground; do not stay on the file list |
| Cannot see output | Dismiss keyboard; landscape; tap the Results tab if needed |
