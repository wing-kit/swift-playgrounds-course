# Swift Playgrounds (iPad) — Basics

Built for **Wing Kit Leung**: learn core Swift in **iPad Swift Playgrounds** from scratch. Lessons use **Blank / plain program output** (`print` for results) — no SwiftUI yet.

Tone: clear teaching English. Parallel to the Mac basics track — you may copy code, but follow **these** steps (touch, file browser, ▶ placement).

When finished, go to [`../lessons/`](../lessons/) advanced (start at 02 SwiftUI App Playground).

---

## How to open (iPad)

1. Install **Swift Playgrounds** from the iPad App Store.
2. Open the app → file browser → top-right **＋** → **Blank** (or a template that can `print`).
3. Tap the editor, clear the sample; paste “Full code” from `lessons/B0X-….md`.
4. Press toolbar **▶**; scroll to the results pane (landscape helps show code + results).
5. If the on-screen keyboard covers results: dismiss it, or use a hardware keyboard.
6. `snippets/` can be opened in the **Files** app (if you downloaded the course via GitHub / AirDrop).

> This curriculum will not remotely change your iPad.
